# src/web — правила слоя

Читать вместе с корневым [CLAUDE.md](../../CLAUDE.md).

Рендерер на React + Vite. Источник по UI — JSON-поправка Web UI Screen Atlas
v1.3 в `artifacts/atlas/`; legacy filename и исторический Markdown остаются
v1.2. Атлас содержит **376 форм**, **1672 перехода**, **66 journeys**,
**91 requirement**, **2440 QA-сценариев**.

## Трассируемость

Каждая форма ссылается на свой ID из атласа — в коде и в тестах. Без ID форма
считается не реализованной, даже если она работает.

## renderer/

Generic-рендерер по атласу. Разметка формы выводится из описания в
`generated/spec`, а не пишется вручную под каждый экран. Частный случай, не
выразимый через атлас, — повод дополнить атлас, а не обойти рендерер.

Форма, которой нет в атласе, **не рендерится** (fail-closed). Нет ветки по
умолчанию и нет «пустого экрана на всякий случай».

## Клиент не авторитет

- Никаких игровых решений на клиенте. Результат считает хост.
- Клиент не фильтрует чужие данные — он их просто не получает. Если данные
  пришли, значит роль имеет на них право.
- Проверка ввода на клиенте — подсказка пользователю, а не защита. Хост
  проверяет заново.

## Автономность сборки

Приложение offline-first: бандл self-contained. Никаких CDN, внешних шрифтов и
сетевых запросов в рантайме, кроме самого хоста. Арты и иконки приходят из
`generated/media`.

## Тесты
