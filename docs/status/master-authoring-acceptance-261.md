# Мастерские формы до Start — матрица #261

Мастер PAUSED-кампании с нулём активных персонажей открывает CMP-007 из CMP-006.
Из одного GM-001 он создаёт постоянного НПС, врага-мыслящего или произвольного
монстра. Версия сохраняется с выбранным артом, а история позволяет прочитать
данные именно той версии, которую выбрал мастер. Родительский объём определён
в [#113](https://github.com/tixonowar-ui/Symbiosis-V7/issues/113),
[#188](https://github.com/tixonowar-ui/Symbiosis-V7/issues/188) и
[#261](https://github.com/tixonowar-ui/Symbiosis-V7/issues/261).

Родительские #113/#188 охватывают перечисленные строки формы и связанные с ними
части QA-REQ-011–015/065. Остальные ветви этих требований, включая Start,
боевую обстановку и удаление, имеют отдельный объём.

Для НПС хост проверяет нижнюю и верхнюю границы массы и шаг 0,1 кг для каждой
пары расы и пола. У PURE диапазоны составляют 60–400 кг для мужчин и 40–350 кг
для женщин, у UNITED — 30–150 и 25–120 кг, у FREE — 40–200 и 30–160 кг
соответственно. Для каждого из 44 системных шаблонов отдельно сверяются
`NO_XP_PROGRESSION`, хэш полного payload и хэш PNG из замороженного Runtime Pack.
[Границы массы НПС](../../src/host/npc-catalog.test.ts), [каталог системных шаблонов](../../src/host/enemy-catalog.test.ts).

До Start ещё нет экземпляров противников в бою. После сохранения N+1 хост
возвращает прежнюю версию с теми же данными и пустой список `activeCombatPins`.
Контракт истории отклоняет присланный идентификатор вымышленного боевого
экземпляра. Для закрытия #188 требуется сверить весь этот мастерский сценарий
после поставки #261. Для #113 дополнительно сверяются поставка #186, сценарии НПС
из #187 и завершение #188. [История версий](../../src/host/enemy-version-application.test.ts),
[проверка привязок](../../src/shared/enemy-version-history.test.ts).

## Проверка арта по #261

Для каждого из SENTIENT и CUSTOM_MONSTER сверяются два разных шаблона.
У первого V1 сохраняет точные байты поставленной заглушки своего вида.
У второго V1 сохраняет байты файла, MIME и SHA-256, подтверждённые хостом.
Следующая версия наследует изображение. Явная замена сохраняет другие байты,
явная очистка возвращает заглушку своего вида. После физического перезапуска
в ENM-020 по очереди выбираются старые и текущая версии. Для каждой должны
совпасть изображение, MIME и SHA-256 именно этой версии.

Хостовые тесты сохраняют четыре версии каждого вида в одной SQLite-базе,
переоткрывают её и выбирают каждую версию из истории. Отдельно проверяются
хэш изображения в квитанции броска монстра, откат при отказе записи BLOB и
повтор прежней команды после очистки. [Версии и бросок](../../src/host/monster-stat-roll-application.test.ts),
[повтор и откат](../../src/host/enemy-authoring-application.test.ts).

В миграции 0025 каждая загрузка связана с событием мастерской очереди по ID
команды. При восстановлении хост сверяет её тип, размер и SHA-256 с байтами
в SQLite. Проверка читает по одному изображению, а её продолжительность
зависит от суммарного объёма загрузок кампании. [Проверка целостности](../../src/persistence/enemy-art-store.test.ts).

Отдельные проверки должны подтвердить, что отмена и ошибочная загрузка
оставляют версии и currentVersion прежними, а незавершённая загрузка блокирует
сохранение. Проверяются предельный размер и превышение на один байт, подмена
MIME, несовпадение bytes/hash, неизвестный ключ, путь или mapping, устаревшая
ревизия и чужая попытка/версия. PLAYER не получает мастерские идентификаторы,
адреса или байты через доступный ему канал, DOM, атрибуты либо дерево
доступности. У НПС сохраняется собственная проверка полномочий и выбор портрета.

В тесте протокола файл с JPEG-сигнатурой размером 12 МиБ занимает ровно 16 МиБ
в base64. Добавление одного байта вызывает отказ. Хост отдельно проверяет
эту же границу для файла с PNG-сигнатурой. Браузерные сценарии используют
небольшие декодируемые JPEG и PNG и сравнивают SHA-256 отображённых байтов.
[Размер в протоколе](../../src/shared/enemy-art.test.ts), [размер на хосте](../../src/host/campaign-draft-validation.test.ts), [выбор файла в Chrome][versions].

Браузерные сценарии `GM replaces the full SENTIENT N+1 configuration and edits version portraits…`
и `GM replaces the full CUSTOM_MONSTER N+1 configuration and edits version portraits…`
подают реальный JPEG через файловый ввод формы создания. На ENM-017 проверяют
унаследованный предпросмотр и загружают PNG. SENTIENT сохраняет замену;
CUSTOM_MONSTER явно очищает выбор перед сохранением. После отмены следующей попытки
и перезапуска оба сценария сверяют историю и SHA-256 изображения, которое
фактически отображает браузер. Отдельная сессия PLAYER проверяет полученные
кадры, DOM с атрибутами и дерево доступности. [Сценарии версий][versions]

**Статус проверки.** Матрица описывает покрытие в исходниках. Общая приёмка
остаётся открытой до полного чистого цикла окончательного коммита, независимого
ревью, CI и сверки дерева после merge.
