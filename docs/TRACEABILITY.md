## Как это будет считаться

`tools/traceability` сопоставляет три множества и переписывает этот файл:

1. **Ожидается** — ID из `generated/spec` (формы, переходы, правила, journeys)
2. **Реализовано** — ID, на которые есть ссылка в `src/`
3. **Покрыто** — ID, на которые есть ссылка в тестах

Форма считается реализованной только при явной ссылке на её ID из атласа.
Работающий экран без ссылки на ID не засчитывается: правило трассируемости
существует именно для того, чтобы покрытие нельзя было получить случайно.

Расхождение множеств — повод для отчёта, а не для округления: ID, найденный в
`src/`, но отсутствующий в `generated/spec`, это ошибка не меньшая, чем
нереализованная форма.
