# 0004 — Генерация SQLite seed

- Веха: **M2**
- Размер: средняя
- Метки: `task`, `M2`
- **Блокируется задачей 0003** — без схемы делать нечего

## Контекст

Последний незакрытый пункт конвейера. `generated/seed/` пуст.

Seed — это `generated/spec`, разложенный по таблицам схемы: 739 правил,
376 форм, 67 типов эффектов, 64 предмета, 16 видов, 44 системных шаблона,
1144 payload-сущности Character.

## Критерии приёмки

- [ ] `npm run import` дополнительно собирает `generated/seed/seed.sqlite`
- [ ] Файл детерминирован **побайтово**. Это нетривиально: SQLite пишет
      служебные страницы и может зависеть от порядка вставки и версии
      библиотеки. Если побайтовый детерминизм окажется недостижим —
      остановиться и завести issue с описанием причины, а не ослаблять
      требование молча
- [ ] Все каталоги из `generated/spec` присутствуют в seed в полном объёме
- [ ] Количество строк в каждой таблице сверяется с длиной соответствующего
      файла `generated/spec`
- [ ] Тест открывает собранный seed и проверяет счётчики
- [ ] `generated/seed` остаётся в git (ADR 0016)

## Как проверяется результат

```bash
npm run import && npm run verify
```

Детерминизм — два прогона и сравнение хеша `generated/seed/seed.sqlite`.

Только `generated/spec`. Seed ничего не добавляет к данным — он меняет форму
хранения.
