# 0002 — Генератор матрицы трассируемости

- Веха: **M1**
- Размер: средняя
- Метки: `task`, `M1`

## Контекст

`docs/TRACEABILITY.md` сейчас ведётся руками. Каждый импорт требует вручную
поправить проценты, и это уже расходилось с фактом.

`tools/traceability/` — пустой каталог. Нужен инструмент, который считает
покрытие по репозиторию и переписывает файл.

Правило трассируемости из CLAUDE.md: форма считается реализованной **только**
при явной ссылке на её ID из атласа. Работающий экран без ссылки не
засчитывается — иначе покрытие можно получить случайно.

## Критерии приёмки

- [ ] `npm run traceability` переписывает `docs/TRACEABILITY.md`
- [ ] Инструмент сопоставляет три множества:
      **ожидается** — ID из `generated/spec`;
      **реализовано** — ID, на которые есть ссылка в `src/`;
      **покрыто** — ID, на которые есть ссылка в тестах
- [ ] Считаются: формы (376), переходы (1672), journeys (66), requirements
      (91), QA-сценарии (2440), активные правила (699), tombstone (40),
      entity lifecycles (19), guard-состояния (10), проекции ролей (3)
- [ ] Разбивка форм по 16 доменам и по 6 типам
- [ ] ID, найденный в `src/`, но отсутствующий в `generated/spec`, попадает в
      отдельный раздел «расхождения» — это ошибка не меньшая, чем
      нереализованная форма
- [ ] Вывод детерминирован: два прогона подряд дают одинаковый файл.
      **Дата снимка берётся из последнего коммита**, а не из системных часов,
      иначе детерминизм ломается
- [ ] `npm run verify` дополнительно проверяет, что матрица не устарела:
      прогон генератора не должен менять файл
- [ ] Тесты на подсчёт покрытия

## Затрагиваемые модули и ID

- `tools/traceability/` — новый инструмент
- `docs/TRACEABILITY.md` — становится генерируемым
- `package.json` — новая команда

## Чего касаться нельзя

- `artifacts/**`, `generated/**`
- Формат существующих разделов `TRACEABILITY.md` менять можно, но
  величины «всего» обязаны сходиться с `generated/spec`

## Как проверяется результат

```bash
npm run traceability && git diff --exit-code docs/TRACEABILITY.md
npm run verify
```

Первый прогон обновляет файл, второй не должен менять ничего.

## Источник в артефактах

Все величины «всего» — из `generated/spec`, не из головы и не из текущего
текста `TRACEABILITY.md`.
