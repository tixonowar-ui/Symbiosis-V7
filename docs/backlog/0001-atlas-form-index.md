# 0001 — Индекс форм атласа по ID

- Веха: **M1**
- Размер: **маленькая** (обкатка процесса)
- Метки: `task`, `M1`

## Контекст

Это первая задача второго агента. Она намеренно небольшая и хорошо
изолированная: цель — пройти весь путь (ветка → код → тест → CI → PR), а не
закрыть объём.

`generated/spec/atlas/forms.json` — массив из 376 форм. Любой потребитель,
которому нужна форма по её ID, вынужден линейно искать по массиву. Рендереру на
вехе M5 это понадобится постоянно.

Нужен производный индекс: `id → форма`. Он строится тем же конвейером, теми же
гарантиями (ADR 0015), и укладывается в один новый файл плюс тест.

## Критерии приёмки

- [ ] `tools/import/atlas.ts` дополнительно выгружает
      `generated/spec/atlas/forms-by-id.json` — объект, где ключ это ID формы,
      значение — та же запись, что в `forms.json`
- [ ] Ключей ровно 376
- [ ] Для каждого ID значение **идентично** соответствующему элементу
      `forms.json` (сравнение по глубокому равенству в тесте)
- [ ] Импорт остаётся детерминированным: два прогона подряд дают побайтово
      одинаковый файл
- [ ] `npm run validate` дополнительно проверяет, что множество ключей
      `forms-by-id.json` совпадает с множеством `id` из `forms.json`
- [ ] Тесты в `tools/import/atlas.test.ts` покрывают количество ключей и
      совпадение содержимого
- [ ] `docs/status/module-map.md` обновлён

## Затрагиваемые модули и ID

- `tools/import/atlas.ts`
- `tools/import/atlas.test.ts`
- `tools/validate/index.ts`
- ID: все 376 форм атласа, поимённо не перечисляются

## Чего касаться нельзя

- `artifacts/**`
- Существующие выгрузки атласа — `forms.json` и остальные семь файлов не
  меняются ни по содержимому, ни по формату
- Проверки в `importAtlas`, которые уже есть: `counts`, распределение по
  доменам, замкнутость переходов, совпадение префикса ID с доменом

## Как проверяется результат

```bash
npm run import && npm run verify && npm run validate
```

Плюс детерминизм — два прогона и сравнение:

```bash
npm run import && sha256sum generated/spec/atlas/forms-by-id.json
npm run import && sha256sum generated/spec/atlas/forms-by-id.json
```

Хеши обязаны совпасть.

## Источник в артефактах

`artifacts/atlas/Symbiosis_V7_Web_UI_Screen_Atlas_v1.2.json`, массив `forms`.
Новых данных не появляется — только другой способ адресации уже
импортированных.

## Подсказка

`writeJson` из `tools/import/lib/emit.ts` сортирует ключи объектов. Для индекса
это то, что нужно: порядок ключей не будет зависеть от порядка форм в атласе.
