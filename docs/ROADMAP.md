# Дорожная карта

> Заготовка. Вехи намечены по структуре артефактов; сроки не проставлены
> намеренно — они появятся, когда объём каждой вехи будет измерен.

Принцип: веха закрыта, когда её покрытие подтверждено `docs/TRACEABILITY.md`, а
не когда «в целом работает».

## M0 — Каркас ✅

Выполнено 2026-08-06.

- Структура репозитория, Node 24 LTS, TypeScript strict
- Линтер, форматтер, vitest, Playwright
- `artifacts/` разложены и покрыты `CHECKSUMS.sha256` (13 файлов)
- ADR 0001–0003, CLAUDE.md корневой и по слоям
- Первый коммит
- Решения аудита перенесены в ADR 0004–0013 (2026-08-07)

## M1 — Конвейер импорта

`tools/import`: `artifacts/` → `generated/`.

- Чтение xlsx-реестров и атласа (json)
- `generated/types` — TS-типы из атласа и реестров
- `generated/spec` — формы, правила, journeys в машинном виде
- `generated/seed` — SQLite seed
- Конвейер детерминирован: одинаковый вход → побайтово одинаковый выход
- Расхождение с `CHECKSUMS.sha256` останавливает импорт

## M2 — Хранилище

- Схема БД из `generated/spec`
- Миграции только вперёд, нумерованные
- Применение seed
- Тесты на путь миграций с нуля до актуальной версии

## M3 — Движок правил

- Реестр handler'ов без ветки по умолчанию (fail-closed)
- 699 активных правил, 40 tombstone
- 70 операций, 106 workflow-команд
- 19 entity lifecycles с явными переходами
- Тест на правило ссылается на его ID из реестра

## M4 — Хост и проекции

- Fastify: статика и HTTP
- ws: канал состояния
- Проекции `player` / `gm` / `system`

## Вне текущего объёма

- ARM64, x86, Windows до 10 (1809) — см. [ADR 0001](adr/0001-target-platforms.md)
- Мультихостовые и облачные сценарии — противоречат offline-first
- Боевой ИИ и автовыбор цели — исключены `CORE-215`,
  см. [ADR 0005](adr/0005-balanced-enemy-group-generator.md)
- Откат, удаление и компенсация начисленного опыта — обратных операций не
  существует, см. [ADR 0004](adr/0004-gm-xp-award-is-irreversible.md)
