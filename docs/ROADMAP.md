# Дорожная карта

> Заготовка. Вехи намечены по структуре артефактов; сроки не проставлены
> намеренно — они появятся, когда объём каждой вехи будет измерен.

Принцип: веха закрыта, когда её покрытие подтверждено `docs/TRACEABILITY.md`, а
не когда «в целом работает».

## M0 — Каркас ✅

Выполнено 2026-08-06.

- Линтер, форматтер, vitest, Playwright

- Первый коммит
- Решения аудита перенесены в ADR 0004–0013 (2026-08-07)

## M1 — Конвейер импорта ✅

Выполнено 2026-08-09.

`tools/import`: `artifacts/` → `generated/`. Запуск — `npm run import`.

Сделано:

- Гейт контрольных сумм перед чтением: расхождение останавливает импорт
  с ненулевым кодом, до единого прочитанного байта артефакта
- Детерминизм: ключи объектов сортируются, порядок массивов сохраняется,
  LF, никаких меток времени. Подтверждено повторным прогоном — вывод
  совпадает побайтово
- Fail-closed доступ к JSON и листам xlsx: лист берётся по имени,
  неизвестное поле или тип называются явно
- Атлас v1.2 → `generated/spec/atlas` (13 файлов) и `generated/types/atlas.ts`,
  включая 106 структурированных контрактов workflow-команд
- Сверка атласа с самим собой: объявленные `counts`, распределение по
  16 доменам, замкнутость 1672 переходов на каталог форм, совпадение
  префикса ID с доменом
- Executable Rules v1.7 → `generated/spec/rules` (6 файлов) и
  `generated/types/rules.ts`: 739 карточек, 699 активных, 40 tombstone,
  4621 параметр, 876 связей, 250 статей справочника
- Гейт по листу «Контроль» реестра правил: все 99 строк обязаны быть PASS
- Замкнутость параметров и связей на каталог правил
- Character / Skills / Symbionts v1.2 → `generated/spec/character` (22 файла) и
  `generated/types/character.ts`: 1144 payload-сущности, 167 способностей,
  74 вида симбионтов, 7 характеристик
- Два гейта Character: паспорт (21 строка) и контроль (48 строк), все PASS
- Перекрёстная проверка: 291 строка трассировки правил разрешается в каталог
  Executable Rules

- `24_XP_Runtime` разобран посекционно: 9 секций, 66 строк →
  `generated/spec/character/xp-runtime`. Секции перечислены по названиям, а не
  распознаются по форме: у A–G заголовок размазан по всем колонкам, у H и I
  стоит только в первой, и любая эвристика молча теряет две секции
- Импорт сверяет инварианты [ADR 0004](adr/0004-gm-xp-award-is-irreversible.md)
  с их источником: множитель `FREE` = 2 и отсутствие обратной команды у
  начисления. Расхождение останавливает импорт

- Item Registry v1.6 → `generated/spec/items` (20 файлов) и
  `generated/types/items.ts`: 64 типа предметов, 157 строк трассировки правил,
  65 боевых значений, гейт по листу «Контроль» (84 строки)
- **`generated/media` заработал**: 64 иконки извлечены в
  `generated/media/items`. Связь «изображение → предмет» берётся из якорей
  OOXML (`xl/drawings/`), а не из порядка файлов в `xl/media/` — там
  `image10.png` сортируется раньше `image2.png`, и совпадение было бы
  случайным. Результат сверяется с колонкой `FileName` самого реестра

- Effects and Diseases v1.2 → `generated/spec/effects` (20 файлов) и
  `generated/types/effects.ts`: 67 типов эффектов, 24 семейства, 306 строк
  карты источников, 300 пар матрицы семейств. Гейт по «20_Контроль» (24 строки)
- Импорт сверяет [ADR 0011](adr/0011-not-modeled-stays-tombstone.md) с
  источником: ровно один `NOT_MODELED` тип — `EFF-SENSE-BLINDNESS` со статусом
  `EXCLUDED_FROM_RUNTIME`, и 66 моделируемых, как заявляет атлас

- Canonical Bestiary v1.4 → `generated/spec/bestiary` (17 файлов),
  `generated/media/bestiary` (16 артов, 5,5 МБ) и
  `generated/types/bestiary.ts`: 16 видов, 17 статблоков, 119 строк
  характеристик. Гейт по «12_Контроль» (49 проверок + 1 подзаголовок секции)
- Галерея бестиария — сетка, а не список: два арта в ряд, подпись под каждым в
  своей колонке. Арт сопоставляется с ближайшей подписью ниже в той же колонке,

- Default Sentient Enemy v1.2 + Runtime Pack → `generated/spec/sentient`
  (13 файлов), `generated/media/sentient` (44 арта, 16,2 МБ) и
  `generated/types/sentient.ts`: 44 замороженных шаблона (12 PURE / 16 FREE /
  16 UNITED), 1195 QA-проверок. Гейты — паспорт (8 строк) и QA (1195)
- Проверка [ADR 0007](adr/0007-frozen-runtime-pack-forward-compatibility.md):
  пакет принят по forward assertion, его `dependencyTuple` намеренно старше

- Проверка RTC-011 дважды: по листу контракта и построчно по всем 44 шаблонам
  (`ActorType`, `ProgressionPolicy`, `Immutable`)
- Реестр и замороженный пакет сверены между собой: 44 SHA-256 артов и
  44 payload-хеша совпали
- All Questions and Answers v1.2 → `generated/spec/qna` (6 файлов) и

- `generated/seed/seed.sqlite`: 113 таблиц массивов, 20 641 строка и отдельная
  таблица восьми паспортов разделов. Пять объектных JSON-индексов не дублируются;
  файл побайтово воспроизводим на закреплённой SQLite 3.53.4 и пересобирается
  по ADR 0019

**Все предусмотренные M1 категории вывода `generated/` производятся; веха

## Вне текущего объёма

- ARM64, x86, Windows до 10 (1809) — см. [ADR 0001](adr/0001-target-platforms.md)
- Мультихостовые и облачные сценарии — противоречат offline-first
- Боевой ИИ и автовыбор цели — исключены `CORE-215`,
  см. [ADR 0005](adr/0005-balanced-enemy-group-generator.md)
- Откат, удаление и компенсация начисленного опыта — обратных операций не
  существует, см. [ADR 0004](adr/0004-gm-xp-award-is-irreversible.md)
