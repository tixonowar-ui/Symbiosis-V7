# ADR 0015 — Гарантии конвейера импорта

- **Статус:** принято
- **Дата:** 2026-08-08

## Контекст

`tools/import` превращает 12 поставленных артефактов в `generated/`. Ошибка
здесь не проявляется как падение: она проявляется как **правдоподобно
выглядящий, но неверный** `generated/spec`, из которого потом собирается вся
игровая логика. Обнаружится это через несколько вех, на отладке боя.

Три конкретных способа получить такую ошибку, все встреченные на практике:

- прочитать не тот лист (первый лист реестра — обычно «Сводка», и чтение по
  индексу молча возвращает 24 строки вместо 444);
- сопоставить изображения с записями по порядку файлов (`image10.png`
  сортируется раньше `image2.png`);
- принять артефакт, который противоречит сам себе, — например книгу, где
  собственная контрольная ведомость показывает FAIL.

## Решение

Конвейер даёт четыре гарантии. Все они проверяются автоматически.

### 1. Гейт целостности до чтения

`artifacts/CHECKSUMS.sha256` сверяется **до того**, как прочитан первый байт
артефакта. Расхождение останавливает импорт с ненулевым кодом.

### 2. Детерминизм

Одинаковый вход даёт побайтово одинаковый выход. Ключи объектов сортируются,
порядок массивов сохраняется (в атласе он несёт смысл), концы строк — LF,
никаких меток времени, имён хостов и идентификаторов прогона.

Проверяется двумя прогонами подряд со сравнением хешей всех файлов
`generated/` — на момент решения это 247 файлов.

### 3. Fail-closed на каждом шаге

Неизвестный лист, колонка, статус или тип связи — отказ с указанием того, что
именно не распознано. Ни одной ветки «по умолчанию».

Листы адресуются **по имени**, никогда по индексу. Строка заголовка задаётся
явно: реестры не единообразны, у одних шапка на строке 0, у других после двух
строк заголовка и примечания.

### 4. Самопроверка артефакта и перекрёстные ссылки

Каждый реестр несёт собственную контрольную ведомость. Импорт использует её как
гейт: хотя бы одна строка не `PASS` — книга противоречит сама себе и не
импортируется.

Сверх этого проверяются:

- объявленные величины (`counts` атласа, паспорта реестров) против фактических;
- замкнутость графов — 1672 перехода атласа на каталог форм, 876 связей правил
  на каталог правил;
- перекрёстные ссылки между реестрами — Character, Items, Effects и Бестиарий
  разрешают свои `Rule ID` в каталог Executable Rules;
- согласие независимых артефактов — 44 SHA-256 артов и 44 payload-хеша
  Sentient совпадают между реестром и замороженным Runtime Pack.

### 5. ADR застрахованы кодом

Решения, снятые с артефактов, проверяются против источника при каждом импорте:

| Проверка                   | Что защищает                                            |
| -------------------------- | ------------------------------------------------------- |
| `assertAdr0004`            | множитель `FREE` = 2; начисление опыта необратимо       |
| `assertAdr0011`            | ровно один `NOT_MODELED` эффект — `EFF-SENSE-BLINDNESS` |
| `assertAdr0007Contract`    | `NO_XP_PROGRESSION` в контракте Sentient                |
| `assertTemplateInvariants` | то же построчно по всем 44 шаблонам                     |

Каждый страж покрыт тестами **на срабатывание**, а не только на успех: подмена
значения и пустой вход обязаны давать отказ. Проверка, которая проходит всегда,
ничего не проверяет.

## Обоснование

Значения берутся из артефакта и сопровождаются ссылкой на источник. Константа
без источника — это выдуманное игровое данное, запрещённое
[CLAUDE.md](../../CLAUDE.md), раздел 4.

Там, где сверка невозможна без придуманного соглашения, она **не делается**, и
причина записывается рядом с кодом. Так вышло с многозначными и составными
ссылками на правила (`SYM-084; SYM-085`, `CORE-155–156`, `SYM-131#MI_MI_MI`) и
с колонкой `Effect family`, где словарь шире, чем `FamilyCode`. Наивная сверка
дала бы ложные отказы на здоровом артефакте.

## Альтернативы

- **Распознавать структуру листа эвристикой** — отвергнуто. На листе
  `24_XP_Runtime` секции A–G пишут заголовок во все колонки, а H и I только в
  первую; правило «баннер — это повтор значения по строке» молча теряет две
  секции из девяти, включая политику прямого начисления мастера.
- **Нормализовать словари** (склеить `уточняет` и `Уточняет / имеет
приоритет`) — отвергнуто: эквивалентности нет в артефакте.
- **Доверять одному источнику при извлечении медиа** — отвергнуто. Требуются
  два независимых утверждения: у предметов это якорь OOXML и колонка
  `FileName`, у Sentient — файл пакета и объявленный в реестре SHA-256.

## Последствия

- Импорт не «старается пройти». Он останавливается, и это нормальный режим
  работы при изменившемся артефакте.
- Новая поставка артефактов почти наверняка потребует правки ожидаемых величин
  в `tools/import`. Это осознанная цена: молчаливое расхождение дороже.
- Упавший страж ADR — повод пересмотреть решение, а не ослабить проверку.
- Добавление реестра означает добавление его гейта и перекрёстных ссылок, а не
  только чтение листов.
