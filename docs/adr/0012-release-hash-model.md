# ADR 0012 — Модель хеширования выпуска без цикла

- **Статус:** принято
- **Дата:** 2026-08-01 (перенесено в ADR 2026-08-07)
- **Источник:** Cross-Registry Audit Report v1.2 — AUD-025, RTC-012

## Контекст

Файл, содержащий собственную контрольную сумму, не может её содержать: запись
хеша меняет файл и делает хеш неверным. Аудит зафиксировал эту проблему как
AUD-025.

## Решение

Хеширование выполняется по слоям, каждый следующий охватывает предыдущий:

- **Audit Report** хеширует **10** исходных артефактов
- **Delivery Manifest** хеширует **11** non-self артефактов (10 исходных + сам
  Audit Report)
- Хеш самого манифеста сообщается **внешне**, вне манифеста

Машинный инвариант (RTC-012):

| Контракт | Вход                  | Предусловие               | Переход                       | Запрещено       |
| -------- | --------------------- | ------------------------- | ----------------------------- | --------------- |
| RTC-012  | 10 источников + Audit | финализировать по порядку | манифест хеширует 11 non-self | self-hash книги |

Нормативное основание: release policy. Результат проверки — циклического хеша
нет.

## Обоснование

Решение перенесено из аудита без изменений.

Порядок финализации существенен: артефакт нельзя хешировать до того, как он
финализирован, и нельзя финализировать после того, как его хеш записан в
вышестоящий документ.

## Последствия

- `artifacts/CHECKSUMS.sha256` следует тому же принципу: он покрывает все файлы
  под `artifacts/`, **кроме себя самого**. Инструмент
  [tools/checksums/index.ts](../../tools/checksums/index.ts) исключает
  `CHECKSUMS.sha256` из обхода.
- Целостность самого манифеста контрольных сумм обеспечивается git: файл в
  истории, изменение видно в диффе.
- `npm run checksums:verify` покрывает 13 файлов и обязан проходить перед
  коммитом.
- Попытка «для полноты» внести в манифест его собственную сумму воспроизведёт
  ровно ту ошибку, которую закрыл AUD-025.
