# Architecture Decision Records

Решения проекта. Это **высший источник правды** — выше поставленных артефактов
(см. [ADR 0003](0003-source-of-truth-order.md)).

## Формат

Один файл — одно решение. Имя: `NNNN-краткое-название.md`, номер сквозной,
четыре цифры, не переиспользуется.

Обязательные разделы:

- **Статус** — предложено / принято / заменено ADR NNNN / отклонено
- **Дата**
- **Контекст** — какая проблема и почему решается сейчас
- **Решение** — что именно решено, в утвердительной форме
- **Обоснование** — почему так, с проверяемыми фактами
- **Последствия** — что это меняет, включая неприятное

Принятый ADR не редактируется по существу. Изменение решения — новый ADR,
старый переводится в статус «заменено ADR NNNN».

## Правила

- Утверждение о поведении инструмента или платформы должно быть **проверено**,
  а не взято по памяти. В ADR идёт результат проверки.
- ADR, уточняющий игровое правило, обязан сослаться на артефакт-источник и
  объяснить расхождение. Выдумывать значения нельзя и здесь.
- Отвергнутые альтернативы записываются вместе с причиной отказа.

### Что намеренно не перенесено

Эти записи аудита — гигиена самих артефактов, а не решения проекта. ADR из них
не делается; они остаются в артефакте:

| Записи                                                        | Почему                                                             |
| ------------------------------------------------------------- | ------------------------------------------------------------------ |
| AUD-007, AUD-008, AUD-026, AUD-027, CHG-005, CHG-013, CHG-014 | исправления формул и контролей внутри книг                         |
| AUD-021, CHG-010                                              | синхронизация метаданных Бестиария, содержимое не менялось         |
| AUD-022, CHG-009                                              | синхронизация трассировки Items, только trace                      |
| AUD-006, CHG-008                                              | пополнение Q&A до 444 строк — полнота, а не новое решение          |
| AUD-023                                                       | перечисление артефактов в манифесте — состав поставки              |
| AUD-010, AUD-012…014, AUD-019, AUD-020, CHG-012               | покрытие атласа формами и маршрутами; контракт — сам атлас         |
| CHG-006, CHG-007                                              | расширение операций и payload вслед за 0004 и 0005                 |
| CHK-001…CHK-017                                               | проверки, а не решения; величины отражены в `docs/TRACEABILITY.md` |

Перенос ничего не изменил по существу: формулировки и значения взяты из
артефакта как есть. Аудит остаётся уровнем 8 в иерархии источников
([ADR 0003](0003-source-of-truth-order.md)) — свидетельством консистентности,
а не источником механик. Теперь связывающая часть его содержимого поднята на
уровень 1 в виде ADR 0004–0013.
