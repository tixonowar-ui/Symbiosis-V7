# ADR 0005 — Генератор сбалансированной группы врагов

- **Статус:** принято
- **Дата:** 2026-08-01 (перенесено в ADR 2026-08-07)
- **Источник:** Cross-Registry Audit Report v1.2 — AUD-005, AUD-011, CHG-003,
  CHG-004, RTC-005…RTC-008, Q-ENEMY-B14

## Контекст

Правила `AQA-044` и `CORE-215` запрещали генератор групп врагов, хотя это
сохранённое требование проекта (AUD-005). В атласе UI генератора либо
отсутствовал, либо запрещал сценарий (AUD-011).

Вопрос `Q-ENEMY-B14` закрыт: генератор добавляется.

## Решение

Генератор сбалансированной группы врагов **разрешён**. `AQA-044` и `CORE-215`
изменены: генератор допущен, **ИИ противника исключён**.

Параметры: баланс **80–150 %**, среднее значение характеристик ориентировано на
**80**, потолок характеристики — **35**, состав `sentient + monster`, **без ИИ**.

Формы атласа: `ENM-024`…`ENM-026`.

Машинные инварианты (RTC-005…RTC-008):

| Контракт | Вход                               | Предусловие                   | Переход                                                    | Запрещено                  |
| -------- | ---------------------------------- | ----------------------------- | ---------------------------------------------------------- | -------------------------- |
| RTC-005  | снимок группы, происхождения, seed | стабильная активная группа PC | **только предпросмотр**                                    | мутация шаблона            |
| RTC-006  | `balancePercent`                   | целое `80..150`               | `targetTotal = round(party × percent / 100)`               | скрытый clamp              |
| RTC-007  | семь характеристик врага           | целые, каждая `<= 35`         | `actualTotal = targetTotal`; среднее ориентировано на `80` | боевой ИИ / автовыбор цели |
| RTC-008  | принятие предпросмотра             | результат провалидирован      | атомарный deep-clone в боевую подготовку                   | частичный коммит           |

## Обоснование

Решение перенесено из аудита без изменений.

Существенно, что генератор порождает **предпросмотр**, а не сразу боевой
состав. Шаблоны врагов при этом не изменяются: генератор читает их, но не
пишет.

## Последствия

- Генератор работает по `seed`: одинаковый вход даёт одинаковый результат.
- `balancePercent` вне `80..150` **отклоняется**, а не подрезается молча.
  Скрытый clamp прямо запрещён RTC-006.
- Характеристика выше `35` — ошибка генерации, а не повод округлить вниз.
- Принятие предпросмотра атомарно: либо вся группа попадает в боевую
  подготовку, либо не попадает ничего. Частичный коммит запрещён RTC-008.
- Боевой ИИ и автоматический выбор цели **не реализуются** — они исключены
  `CORE-215` и запрещены RTC-007.
- Формы `ENM-024`…`ENM-026` обязаны ссылаться на свои ID атласа.
