# ADR 0007 — Замороженный Runtime Pack и forward-совместимость

- **Статус:** принято
- **Дата:** 2026-08-01 (перенесено в ADR 2026-08-07)
- **Источник:** Cross-Registry Audit Report v1.2 — AUD-001, AUD-009, RTC-010,
  RTC-011

## Контекст

Проверка совместимости требовала точного совпадения кортежа версий и на этом
основании отвергала замороженный Runtime Pack (AUD-009). Сам обязательный ZIP
в поставке сначала отсутствовал (AUD-001).

## Решение

Замороженные артефакты принимаются по **утверждению о forward-совместимости**,
а не по точному равенству версий.

Механизм: `builtAgainst` + forward assertion + закрепление SHA (AUD-009,
Manifest v1.2). Runtime Pack v1.2 включён в поставку **без пересборки** —
50 файлов, полное совпадение SHA (AUD-001).

Машинные инварианты (RTC-010, RTC-011):

| Контракт | Вход                    | Предусловие               | Переход                         | Запрещено                          |
| -------- | ----------------------- | ------------------------- | ------------------------------- | ---------------------------------- |
| RTC-010  | Pack v1.2 + полный SHA  | forward assertion истинно | принять **44** шаблона `NO_XP`  | равенство точному текущему кортежу |
| RTC-011  | `SYSTEM_SENTIENT_ENEMY` | замороженный payload      | `NO_XP_PROGRESSION` не меняется | поля прогрессии мастера/игрока     |

## Обоснование

Решение перенесено из аудита без изменений.

Смысл в том, что замороженный артефакт собран против **более старого** набора
реестров (`Rules v1.6 | Character v1.1 | Items v1.5_with_icons | Bestiary v1.3`)
и это нормально: он объявлен совместимым вперёд и закреплён по SHA. Требование
точного равенства версий сделало бы заморозку бессмысленной — любой апдейт
соседнего реестра ломал бы приёмку.

## Последствия

- Импортёр сверяет **полный SHA** пакета, а не версии его зависимостей.
- 44 шаблона `NO_XP` принимаются как есть. `NO_XP_PROGRESSION` не
  переопределяется ни мастером, ни игроком.
- Поля прогрессии мастера и игрока к `SYSTEM_SENTIENT_ENEMY` **не
  применяются** — запрещено RTC-011.
- Пакет не пересобирается. Пересборка изменит SHA и нарушит заморозку.
- `artifacts/packs/` в иерархии источников правды — уровень 7: только точные
  системные шаблоны и арт, никогда не источник новых правил
  (см. [ADR 0003](0003-source-of-truth-order.md)).
