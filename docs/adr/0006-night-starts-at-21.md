# ADR 0006 — Игровая ночь начинается в 21:00

- **Статус:** принято
- **Дата:** 2026-08-01 (перенесено в ADR 2026-08-07)
- **Источник:** Cross-Registry Audit Report v1.2 — AUD-004, CHG-011, RTC-009,
  Q-SOUND-NIGHT-001

## Контекст

Soundtrack Registry задавал начало музыкальной ночи в **18:00** (AUD-004). Это
расходилось с игровым временем. Вопрос `Q-SOUND-NIGHT-001` закрыт прямым
ответом автора от 2026-08-01.

## Решение

Ночь — интервал **[21:00, 06:00)** по времени кампании.

Soundtrack Registry v1.1 обновлён (CHG-011): все именованные ячейки используют
21:00.

Машинный инвариант (RTC-009):

| Контракт | Вход                | Предусловие | Переход                              | Запрещено                     |
| -------- | ------------------- | ----------- | ------------------------------------ | ----------------------------- |
| RTC-009  | `campaign dayPhase` | вне боя     | `21:00 → ночной пул`; `06:00 → день` | `localLighting` меняет музыку |

Нормативное основание: Soundtrack `R-007`.

## Обоснование

Решение перенесено из аудита без изменений.

Важная деталь контракта: смена пула привязана к **времени кампании**, а не к
освещению сцены. Тёмное помещение днём не включает ночную музыку — это прямо
запрещено RTC-009.

## Последствия

- Граница интервала полуоткрытая: `21:00` уже ночь, `06:00` уже день.
- Переключение пула происходит **вне боя**. Боевая музыка живёт по своим
  правилам Soundtrack Registry.
- `localLighting` не является входом для выбора музыкального пула.
- Значение 18:00 в любом коде или тесте — регрессия к состоянию до аудита.
