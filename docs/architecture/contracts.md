# Публичные контракты

Что считается контрактом — то есть чего нельзя менять, не сломав потребителя.

**Честная оговорка.** `src/` пока практически пуст: пять якорных `index.ts` с
`export {}`. Контрактов между слоями приложения **ещё не существует** —
замораживать нечего. Реальные контракты сегодня живут в конвейере и его выводе.
Раздел «Контракты слоёв приложения» появится по мере вех M2–M5.

### Как этим пользоваться

Ссылка на несуществующий ID — **ошибка компиляции**, а не находка на ревью:

```ts
import type { FormId } from '@generated/types/atlas.js';

// компилируется
const screen: FormId = 'CMB-014';

// не компилируется — такой формы в атласе нет
const typo: FormId = 'CMB-999';
```

Правило трассируемости из CLAUDE.md держится этим, а не договорённостью.

### Что нельзя

- Переопределять эти типы у себя. Импортировать, не копировать
- Расширять union вручную. Новый ID появляется только новой поставкой артефакта
- Приводить строку к `FormId` через `as`. Если понадобилось — значит ID пришёл
  извне и его надо **проверить**, а не утвердить

## 2. `generated/spec` — контракт формы данных

Файлы под `generated/spec/<раздел>/` — массивы записей, где ключи это имена
колонок исходного листа **как есть**, включая кириллицу и пробелы:

```json
{ "Rule ID": "CORE-001", "Статус": "Активно", "Режим реализации": "..." }
```

Пустые ячейки **опущены**, а не записаны как `null`. Потребитель обязан
считать отсутствующее поле нормальным случаем.

Числовые ячейки остаются числами. `"ID unique": 1` — это `number`.

Инварианты, на которые можно опираться:

- ключи объектов отсортированы (детерминизм, ADR 0015)
- порядок массива — порядок строк в артефакте, он значим
- у каждого раздела есть `meta.json` с источником и счётчиками

Проверяется `npm run validate`.

## 3. `tools/import/lib` — контракт инструментов

Переиспользуемая часть конвейера. Менять сигнатуры — только с обновлением всех
семи модулей импорта.

| Модуль        | Экспорт                                                       | Назначение                     |
| ------------- | ------------------------------------------------------------- | ------------------------------ |
| `fail.ts`     | `ImportError`, `fail`, `required`, `expectCount`              | fail-closed                    |
| `json.ts`     | `asObject`, `asArray`, `asString`, `asNumber`, `expectString` | доступ к JSON с указанием пути |
| `workbook.ts` | `Workbook`, `Table`                                           | чтение xlsx по имени листа     |
| `archive.ts`  | `openArchive`, `embeddedMedia`                                | ZIP                            |
| `media.ts`    | `anchoredImages`                                              | изображения по якорям OOXML    |
| `emit.ts`     | `writeJson`, `writeText`, `stringify`, `tsUnion`, `banner`    | детерминированная запись       |
| `paths.ts`    | `ARTIFACT`, `SPEC_DIR`, `TYPES_DIR`, `MEDIA_DIR`              | пути к артефактам              |

### Инварианты

- `Workbook.table(name, headerRow, requiredColumns)` — лист **по имени**,
  строка заголовка **явно**. Отсутствие листа или колонки — отказ
- `Table.records(keyColumn)` — отказ при дублирующихся именах колонок
- `writeJson` сортирует ключи и пишет LF
- `tsUnion` на пустом множестве даёт `never`, а не `string`

## 4. Стражи ADR

Функции, сверяющие решения с их источником. Экспортированы намеренно — они
покрыты тестами на срабатывание.

| Функция                    | Модуль            | Защищает                                       |
| -------------------------- | ----------------- | ---------------------------------------------- |
| `assertAdr0004`            | `character-xp.ts` | множитель `FREE` = 2, необратимость начисления |
| `assertAdr0011`            | `effects.ts`      | ровно один `NOT_MODELED` эффект                |
| `assertAdr0007Contract`    | `sentient.ts`     | `NO_XP_PROGRESSION` в контракте                |
| `assertTemplateInvariants` | `sentient.ts`     | то же по всем 44 шаблонам                      |

**Ослаблять нельзя.** Упавший страж означает изменившийся артефакт, и это повод
пересмотреть ADR — см. [ADR 0015](../adr/0015-import-pipeline-guarantees.md).
