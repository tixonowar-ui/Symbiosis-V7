## Три контура

Проект делится на три части с разными правилами обращения.

```
  ┌──────────────────────────────────────────────────────┐
  │  artifacts/            READ-ONLY, в git               │
  │  12 поставленных файлов, покрыты SHA-256             │
  │  Источник ВСЕХ игровых данных                        │
  └────────────────────────┬─────────────────────────────┘
                           │  tools/import
                           │  гейт сумм → чтение → сверка → запись
                           ▼
  ┌──────────────────────────────────────────────────────┐
  │  generated/            ТОЛЬКО вывод, руками не править│
  │  spec/  машинный вид      types/ TS-типы              │
  │  seed/  SQLite (M2)       media/ не в git             │
  └────────────────────────┬─────────────────────────────┘
                           │  импорт типов и данных
                           ▼
  ┌──────────────────────────────────────────────────────┐
  │  src/                  приложение. ПОКА ПУСТО         │
  │  shared → domain → persistence → host → web           │
  └──────────────────────────────────────────────────────┘
```

**Направление одностороннее.** Код читает `generated/`, но никогда не пишет
туда. `generated/` производится из `artifacts/`, но никогда не влияет на них.
Обратная стрелка означала бы, что игровые данные подгоняются под удобство кода
— именно то, что запрещает CLAUDE.md, раздел 4.

## Зоны ответственности

| Зона         | Кто владеет      | Как меняется                       |
| ------------ | ---------------- | ---------------------------------- |
| `artifacts/` | автор артефактов | новой поставкой; SHA-256 фиксирует |
| `generated/` | `tools/import`   | прогоном импорта                   |
| `tools/`     | инфраструктура   | обычным PR                         |
| `src/`       | прикладной код   | обычным PR                         |
| `docs/adr/`  | решения          | новым ADR, старый не редактируется |

## Что держит систему честной

Четыре механизма, каждый автоматический:

1. **`CHECKSUMS.sha256`** — артефакт не подменён. Гейт перед импортом
2. **Самопроверка артефакта** — контрольные ведомости реестров как гейты
3. **Перекрёстные ссылки** — реестры разрешают ID друг друга; независимые
   артефакты сверяются между собой (Sentient ↔ Runtime Pack)
4. **Типы из данных** — `FormId`, `RuleId` и прочие делают ссылку на
   несуществующий ID ошибкой компиляции

Подробнее — [ADR 0015](../adr/0015-import-pipeline-guarantees.md).
